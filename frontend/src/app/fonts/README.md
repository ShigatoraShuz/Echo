# ECHO fonts

These Latin WOFF2 variable fonts are the same Google Fonts assets emitted by the previous `next/font/google` production build. They are bundled locally to keep builds independent of Google's font endpoint and its generated CSS loader.

- Manrope: weights 200–800, from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope).
- Cormorant Garamond: normal style, used at weights 400–600, from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond).

Both use the SIL Open Font License 1.1. Their upstream license notices are included alongside the fonts.
