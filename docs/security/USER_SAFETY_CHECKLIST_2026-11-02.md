**Snapshot:** local `main` at `d4d77c2`, including the current uncommitted security and no-GPU validation changes, reviewed 2026-11-02. This is an implementation inventory, not a certification or a claim about the hosted deployment. **How to read this:** `[x]` means the safeguard is present in local code, configuration, migration, or an existing local test. It does **not** mean that its deployed behavior has passed. `[ ]` is work or verification still needed. A partial safeguard is described as such even when part of its code is present.
