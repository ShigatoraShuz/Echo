# Mock analysis contract

The current provider is development/test-only. It accepts an internal request ID, journal text, and language; the journal text never leaves the Node.js process in this phase.

The provider only recognizes explicit fixtures:

- `[MOCK:SCORE=0]` through `[MOCK:SCORE=24]`
- `[MOCK:URGENT=true]`
- `[MOCK:FAIL]`

Ordinary text produces a neutral, clearly labeled mock result. It is not generated by a trained model and is not a clinical assessment. The backend rejects mock analysis in production.
